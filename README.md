# cover-studio

一个纯静态的多比例视频封面编辑器，适合一键适配导出小红书、抖音、b站、等平台封面图，减少多次排版的麻烦，按需上传场景图和人物图，自动人物抠图并导出七种画幅。

## 功能

- 3:4、4:3、9:16、3:2、16:9、1:1、21:9七种画幅实时预览
- RMBG-1.4 本地 ONNX 模型自动抠图，带真实下载进度，失败时自动切换备用模型
- 系统中文字体、标题颜色、可调粗细和位置的马克笔/荧光笔
- 人物限制在图片框内，并针对不同画幅自动缩放
- 10 套 Guizang 杂志与瑞士主题模板，每页两列分页浏览
- 系统字体扫描优先显示中文名称，支持人物、标题、背景三组标签控制
- 背景图片明度、饱和度、暗角与排版调整
- 人物可在图片框顶部溢出，折纸描边使用几何折线轮廓
- GPUPixel 风格人物滤镜：预设、磨皮、美白、亮度、对比度、饱和度、色温和锐化
- 3:4、4:3、9:16、3:2、16:9、1:1、21:9 多平台画幅
- 液态玻璃界面，自适应深浅色和窄屏
- 当前 PNG 与全部画幅 ZIP 批量导出

## 本地运行

```bash
cd cover-studio
python3 -m http.server 4173
```

浏览器打开 `http://localhost:4173`。人物抠图首次使用时会读取项目内的 RMBG-1.4 本地量化模型并显示下载/初始化进度；推理引擎或模型不可用时会自动切换备用方案。

人物滤镜基于 GPUPixel 的滤镜参数模型适配到浏览器 Canvas，仅作用于人物抠图。项目来源与 Apache-2.0 声明见 `THIRD_PARTY_NOTICES.md`。

部署到 GitHub Pages 时请保留单文件模型 `models/model_quantized.onnx`，浏览器通过相对路径读取并显示真实下载进度。44.4MB 模型可使用 GitHub Desktop、GitKraken 等 Git 客户端提交推送；网页端单文件上传限制不影响客户端推送。ONNX Runtime 仍按需从 CDN 加载；图片推理始终在浏览器本地完成。全部封面压缩包命名为“第一行文案-封面.zip”。
